# Supplier onboarding checklist

- [ ] Supplier account is approved for the business.
- [ ] API/feed documentation and access permissions are received.
- [ ] Authentication and token rotation are confirmed.
- [ ] Catalog pagination, rate limits, image terms and inventory update frequency are documented.
- [ ] Wholesale price, recommended retail price and currency semantics are confirmed.
- [ ] Order creation, cancellation, return and tracking endpoints are documented.
- [ ] Supplier payment method and billing schedule are confirmed.
- [ ] Test credentials are separated from production credentials.
- [ ] One test order is completed before live dispatch.
